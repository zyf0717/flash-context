# Specs and history

Current behavior is defined by [the shared contract](../docs/contracts.md),
[CLI](../docs/cli.md), [MCP](../docs/mcp.md), and
[configuration](../docs/configuration.md). Tests verify those contracts.

is implemented. New proposals belong here with an explicit status; completed
plans are historical, not additional current contracts.

contracts were consolidated for v0.4.0. Their immutable versions remain below
and in Git history. Spec identifiers are preserved; later behavior supersedes
historical requirements, including 007's unconditional range merging.
